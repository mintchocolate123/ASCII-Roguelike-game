# 怎麼幫遊戲加東西（mod 教學）

遊戲實際的內容——卡牌、怪物、關卡、規則——全部放在這個 `mods/` 資料夾裡，用 JSON 資料檔
描述（進階效果才需要寫一點 Python）。想幫遊戲加東西，完全不需要碰 `engine/` 底下的程式碼，
只要在這裡新增或修改檔案就好。

## 最快的第一步

跟著下面做一次，五分鐘內就能在遊戲裡看到自己加的卡。

**1. 複製 `example_mod` 整個資料夾**，貼在 `mods/` 裡，改名成你自己的 id，例如 `my_mod`
（資料夾名稱只能用小寫英文字母、數字、底線，而且開頭一定要是英文字母，因為引擎會直接拿
資料夾名稱當作這個 mod 的 id）。

**2. 打開新資料夾裡的 `mod.json`**，把 `id` 和 `name` 改成你自己的（`id` 一定要跟資料夾
名稱完全一樣）：

```json
{"id": "my_mod", "name": "我的第一個 mod", "version": "1.0.0", "author": "你的名字", "depends": ["core"]}
```

**3. 打開 `cards.json`**，在陣列裡加一筆新卡牌（記得前一筆的結尾要補上逗號）：

```json
{"id": "fireball", "name": "火球術", "type": "attack", "cost": 2, "damage": 15, "count": 1, "in_reward_pool": true}
```

這裡把 `count` 設成 `1`，讓它一開始就會被放進起始牌組，比較快看得到；之後想讓它變成打贏
戰鬥才能抽到的獎勵卡，再把 `count` 改回 `0` 就好（見下面「新增卡牌」欄位說明）。

**4. 存檔。**

**5. 執行 `python main.py --enemy core:slime`**（這是開發測試用的模式，會直接開始一場戰鬥，
略過主選單；每次按 **F5** 都會用磁碟上最新的 `cards.json` 重新組出整副牌，最適合邊改邊看）。
開場印出的載入報告如果沒有提到你的 mod，代表載入成功；戰鬥畫面的手牌裡應該就會看到「火球術」
——如果第一手沒抽到，結束一兩次回合、抽到新的牌就會看到。

如果遊戲視窗已經開著（不管是這個開發模式還是一般的 `python main.py`），改完檔案後直接按
**F5**（終端機模式按 `r`）就會立刻重新讀取，不用整個關掉重開。

## 新增卡牌

在你的 mod 資料夾的 `cards.json` 裡，是一個卡牌物件組成的陣列。每張卡可以用的欄位：

| 欄位 | 意思 | 可以填什麼 | 限制 |
|---|---|---|---|
| `id` | 這張卡在你的 mod 裡的識別碼 | 小寫英文字母、數字、底線，開頭要是英文字母 | 同一個 mod 裡不能重複；引擎會自動組成 `你的mod_id:id` 這種「完整 id」給其他地方引用 |
| `name` | 顯示名稱 | 任何文字 | 顯示寬度最多 10 格，等於**最多 5 個中文字**（半形字元可以到 10 個）；超過會被拒絕，這筆資料跳過 |
| `type` | 卡牌類型 | `"attack"`、`"skill"`、`"power"` 三選一 | 決定卡片框線顏色跟底部標籤（攻擊／技能／能力） |
| `cost` | 出這張卡要花的能量 | 0 到 5 的整數 | 超出範圍會被拒絕 |
| `description` | 卡片描述 | 可以省略；也可以自己寫一段文字，裡面能用 `{damage}`、`{hits}`、`{block}`、`{heal}`、`{draw}`、`{energy}`、`{self_damage}` 這幾種佔位符，引擎會自動代入這張卡對應欄位的數值 | 省略時引擎會依你填的數值欄位自動產生一段描述。不管是自己寫的還是自動產生的，**代入數值、換行後最多只能有 6 行**，超過會被拒絕；佔位符只能引用「這張卡自己有填值」的欄位，引用不存在或沒填的欄位會被拒絕 |
| `count` | 遊戲開局時，牌組裡預先放幾張這張卡 | 0 以上的整數，預設 `1` | `0` 表示這張卡不會出現在起始牌組，只會出現在獎勵池（打贏戰鬥後的三選一） |
| `in_reward_pool` | 這張卡會不會出現在戰鬥後的獎勵池 | `true` / `false`，預設 `true` | 設成 `false` 就只能靠 `count` 放進起始牌組，玩家沒辦法在遊戲過程中抽到 |
| `damage` | 造成的傷害 | 0 以上的整數 | 可省略 |
| `hits` | 上面的傷害要重複幾次 | 1 以上的整數 | 要搭配 `damage` 才有意義；例如 `damage: 3, hits: 3` 就是「造成 3 點傷害，重複 3 次」，每次命中分開計算護盾吸收 |
| `block` | 獲得的護盾 | 0 以上的整數 | 可省略 |
| `heal` | 回復的生命值 | 0 以上的整數 | 可省略 |
| `draw` | 額外抽幾張牌 | 0 以上的整數 | 可省略 |
| `energy` | 額外獲得幾點能量 | 0 以上的整數 | 可省略 |
| `self_damage` | 對自己造成的傷害 | 0 以上的整數 | 不會被自己的護盾擋掉 |
| `effect` | 進階效果：引用一個用 Python class 實作的特殊效果 | 完整 id，格式是 `mod_id:效果id` | 這個 id 要先在你 mod 的 `scripts/*.py` 裡用 `@register_effect()` 註冊過，沒註冊會被拒絕；**有填 `effect` 就一定要自己寫 `description`**，引擎沒辦法從程式碼推測效果內容要怎麼描述 |
| `overrides` | 要覆寫哪一張既有的卡 | 完整 id，例如 `core:strike` | 見下面「修改既有內容」一節 |

完整範例（不需要 `effect`，靠資料欄位就能組出來的效果）：

```json
{
    "id": "fireball",
    "name": "火球術",
    "type": "attack",
    "cost": 2,
    "damage": 15,
    "count": 0,
    "in_reward_pool": true
}
```

沒寫 `description` 的話，引擎會自動產生「造成 15 點傷害。」。

## 新增怪物

在 `enemies.json` 裡是一個怪物物件組成的陣列：

| 欄位 | 意思 | 可以填什麼 | 限制 |
|---|---|---|---|
| `id` | 這隻怪物的識別碼 | 小寫英文字母、數字、底線，開頭要是英文字母 | 同一個 mod 裡不能重複 |
| `name` | 顯示名稱 | 任何文字 | 顯示寬度最多 16 格，約**最多 8 個中文字** |
| `tier` | 這隻怪物會出現在哪個強度的戰鬥 | `"normal"`、`"elite"`、`"boss"` 三選一 | 關卡（`run.json`）的每一場戰鬥都指定一個 tier，同一個 tier 有好幾隻怪物時會隨機選一隻上場 |
| `hp` | 血量上限 | 1 以上的整數 | |
| `art` | ASCII 圖的檔名 | 相對於這個 mod 底下 `art/` 資料夾的檔名，例如 `"training_dummy.txt"` 對應 `mods/你的mod/art/training_dummy.txt` | 圖檔最大 **24 欄 × 10 列**，**只能用半形英數字與符號**（不能有中文、全形符號，也不能有奇怪的控制字元）；超過尺寸會自動裁切（會有警告，怪物還是能用），出現不合法的字元這隻怪物會直接停用 |
| `color` | ASCII 圖的顏色 | `"white"`、`"red"`、`"green"`、`"cyan"`、`"yellow"`、`"blue"`、`"gray"`、`"magenta"` 其中之一，預設 `"white"` | |
| `actions` | 這隻怪物的行動循環 | 一個清單，每一項是 `{"type": "attack" 或 "block", "value": 數字}` | 至少要有一項；戰鬥中會照清單順序循環執行，例如清單有 3 個動作，第 4 次行動會回到第 1 個 |
| `overrides` | 要覆寫哪一隻既有的怪物 | 完整 id，例如 `core:slime` | 見下面「修改既有內容」一節 |

完整範例，先建立 `mods/你的mod/art/training_dummy.txt`：

```
 _____
|o   o|
|  >  |
|_____|
  | |
 /   \
```

再到 `enemies.json` 加一筆：

```json
{
    "id": "training_dummy",
    "name": "訓練假人",
    "tier": "normal",
    "hp": 20,
    "art": "training_dummy.txt",
    "color": "gray",
    "actions": [
        {"type": "attack", "value": 4},
        {"type": "block", "value": 3}
    ]
}
```

## 修改既有內容

想改 core（或別的 mod）已經有的卡牌、怪物，**不能**直接開一張同 `id` 的新資料去蓋掉它——
那會被引擎當成「重複的 id」，只保留原本那一筆、你新加的那筆會被跳過。要修改既有內容，
必須明確宣告 `overrides`，並且在 `mod.json` 的 `depends` 裡加上對方的 mod（不然引擎不知道
要在誰載入之後才套用覆寫）：

```json
{"id": "strike_plus", "name": "斬擊＋", "type": "attack", "cost": 1, "damage": 8, "count": 0, "in_reward_pool": true, "overrides": "core:strike"}
```

這樣寫的意思是：「把 `core:strike` 這張卡的資料整個換成這一筆」，不是把兩筆資料合併起來。
覆寫成功會記錄在開場的載入報告裡，讓你（或任何看報告的人）知道 `core:strike` 為什麼跟原本
的數值不一樣，而不是默默被蓋掉、事後完全找不到原因。

`mods/_example_override/` 就是一個完整的覆寫範例（把 `core:strike` 的傷害從一般值改成 8）。
因為資料夾名稱開頭是底線，引擎預設會跳過它（純粹當範例看）；想實際試玩效果的話，複製整個
資料夾到一個不是底線開頭的名稱（例如 `mods/my_override`），並把 `mod.json` 裡的 `id` 一併
改成跟新資料夾名稱一致。

## 看不懂錯誤訊息怎麼辦

遊戲啟動時（不管是 pygame 視窗還是 `--terminal`），終端機都會先印出一份「載入報告」，列出
每個 mod 載入過程中發生的事。大部分訊息長這樣：

```
mods/<資料夾>/<檔名>，第 N 筆（id：xxx），欄位 欄位名：問題描述，收到的值：實際收到的內容，這筆資料的下場
```

（少數訊息，例如 ASCII 圖的問題，是針對整個檔案的某一行，格式會稍微不一樣，但一樣會告訴你
在哪個檔案、哪裡出問題。）三個實際會遇到的例子：

**1. 欄位數值超出範圍**

```
【警告】 mods/core/cards.json，第 1 筆（id：bad_cost），欄位 cost：數值超出範圍，必須介於 0 到 5，收到的值：99，這筆資料已跳過。
```

`cost` 只能是 0 到 5 之間的整數，這筆資料寫了 `99`。打開 `cards.json`，找到 `id` 是
`bad_cost` 的那一筆，把 `cost` 改成 0～5 之間的數字。

**2. 卡名太長**

```
【警告】 mods/core/cards.json，第 2 筆（id：long_name），欄位 name：卡名太長：顯示寬度最多 10 格（5 個中文字），收到的值：'這是一張名字超長的卡牌'，這筆資料已跳過。
```

卡名超過 5 個中文字的顯示寬度。換一個比較短的名字就好。

**3. ASCII 圖裡有中文**

```
【警告】 mods/core/enemies.json，第 1 筆（id：bad_art）：ASCII 圖檔第 1 行含有不允許的字元（'你'，字元碼 20320），只允許字元碼 32 到 126，已停用。
```

ASCII 圖檔裡出現了中文字（這裡是「你」）。打開對應的 `.txt` 檔，把中文字或全形符號換成
半形的英數字、符號，或直接刪掉那一行重畫。

看到「這筆資料已跳過」或「已停用」，代表**只有這一筆資料失效**，mod 裡其他沒問題的內容
照常能玩，不會讓整個遊戲打不開（除非連 core 本身都完全沒有任何內容能用，那才會是致命錯誤，
遊戲會直接卡在載入畫面）。

## 常見問題

**改了檔案，遊戲裡沒反應？**
記得先存檔，然後在遊戲裡按 **F5**（終端機模式打 `r` 再按 Enter）才會重新讀取。改 JSON 或
Python 檔案只是改了磁碟上的內容，遊戲不會自動偵測變化。

**JSON 少逗號、多逗號？**
陣列或物件裡，每一筆資料**之間**要用逗號隔開，但**最後一筆的後面不能有逗號**。載入報告如果
顯示「不是合法的 JSON」，通常就是這個問題，或是少了一個 `{`、`}`、`[`、`]`。用 VS Code 這類
程式編輯器打開 JSON 檔案，語法錯誤的地方通常會有紅色波浪底線可以直接定位。

**id 重複？**
同一個 mod 裡有兩張卡（或兩隻怪物）用了一樣的 `id`，引擎會保留先出現的那一筆，跳過後面
重複的那一筆，報告裡會分別列出兩筆各自在哪個檔案、第幾筆。把其中一個 `id` 改成不一樣的就好。

**中文引號誤用成全形？**
JSON 的字串一定要用半形的雙引號 `"`，不能用中文輸入法打出來的全形引號「＂」或左右彎引號
「"」「"」。有些筆記軟體或輸入法會自動幫你把引號轉成彎引號，這樣整個 JSON 檔案會直接讀
不出來（報告會顯示「不是合法的 JSON」）。建議用 VS Code 這類不會自動轉換符號的程式編輯器
來改 JSON 檔案。
