# ASCII 卡牌遊戲

一個用 ASCII 字元畫面呈現的簡化版「殺戮尖塔」，用 pygame 視窗顯示（也可以在終端機裡玩）。

本專案以 Python 教學為目的，是 Python 基礎課程的練習專案。架構刻意模仿真實遊戲常見的
mod 系統：遊戲引擎負責畫面、輸入、載入與流程控制，實際的卡牌、怪物、規則全部放在
`mods/` 資料夾裡，以 JSON 資料和一般的 Python 檔案呈現。目的是讓剛學 Python 沒多久的人，
不需要看懂整個引擎，只要新增一筆 JSON 資料、或寫幾行簡單的函式，就能把自己設計的卡牌、
怪物加進遊戲裡，實際玩到自己做的東西。

## 安裝步驟

需要 Python 3.10 以上版本。

### Windows

如果你的電腦還沒裝過 Python：

1. 到 [python.org/downloads](https://www.python.org/downloads/) 下載最新版的 Windows 安裝程式。
2. 執行安裝程式時，**畫面最下面有一個「Add python.exe to PATH」的勾選框，一定要打勾**，再按
   「Install Now」。忘記勾選的話，之後在命令提示字元裡打 `python` 會找不到指令。
3. 安裝完成後，打開「命令提示字元」（cmd）或 PowerShell，輸入 `python --version` 確認能看到
   版本號。

接著在專案資料夾裡建立虛擬環境並安裝套件：

```powershell
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

### Linux / WSL

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

### 重要：一定要用 `pip install -r requirements.txt`

`requirements.txt` 裡指定的套件是 `pygame-ce`，**不是**原版的 `pygame`。網路上大部分教學
文章都是寫 `pip install pygame`，請不要照著打——原版 pygame 目前沒有針對新版 Python 預先
編譯好的安裝檔（wheel），用 pip 安裝時會嘗試從原始碼編譯，如果電腦上沒有對應的編譯工具，
安裝會直接失敗。只要用 `pip install -r requirements.txt` 一次裝好，就會裝到正確、有預編譯
版本可用的 `pygame-ce`，畫面顯示、輸入、聲音等 API 跟原版 pygame 完全相容。

## 執行方式

```bash
python main.py                        # 一般玩法，開啟 pygame 視窗
python main.py --terminal              # 純文字模式，不開視窗，在終端機裡玩
python main.py --no-fx                 # 關閉戰鬥動畫（傷害數字、血條、閃爍抖動等），想快速看
                                        # 修改結果時很好用；可以跟 --terminal 一起用
python main.py --enemy core:slime      # 開發測試用：跳過主選單，直接打一場指定的戰鬥
```

`--enemy` 後面要接怪物的完整 id（`mod_id:怪物id`），core 目前內建的有 `core:slime`、
`core:goblin`、`core:skeleton_knight`、`core:gate_colossus`。

終端機模式（`--terminal`）需要視窗至少有 96 欄、33 列，Windows 內建的命令提示字元預設只有
80 欄，記得先把視窗拉寬，不然遊戲會顯示提示要你放大視窗，不會硬畫出跑版的畫面。

## 操作說明

**滑鼠（pygame 視窗）：**

- 把游標移到一張手牌上，右邊面板會顯示這張卡的詳細說明。
- 點一下手牌：**選取**這張卡——卡片會浮起來一格、邊框變亮，右邊面板固定顯示它的說明。
- 再點一次**同一張**已經選取的卡：真的把它打出去。
- 點選另一張卡：換成選取那一張。點空白處，或按 **Esc**：取消選取。
- 能量不夠打不起的卡，點一下只會顯示說明，不會進入選取狀態。
- 數字鍵 **1–7**：不用兩段式點擊，直接打出手牌裡對應位置的那張卡。
- 結束回合：點畫面上的「結束回合」按鈕，或按 **E**。
- **F5**：熱重載。立刻重新讀取 `mods/` 底下所有的資料跟程式碼，並重新開始目前這場戰鬥（血量、
  手牌等狀態不會保留）。改完 `cards.json` 或 `rules.py` 想馬上看到結果，不用整個關掉遊戲重開。

**終端機模式**沒有滑鼠，用鍵盤輸入代替：`1`–`7` 出牌、`e` 結束回合、`?` 加數字看某張卡的
詳細說明（例如 `?2`）、單獨 `?` 取消檢視、`r` 熱重載、`q` 離開遊戲。

## 我想加東西

想加自己的卡牌、怪物，或修改遊戲平衡，完全不用碰 `engine/` 底下的程式碼，只要在
`mods/` 資料夾裡新增或修改 JSON 檔案（進階一點的效果可以加少量 Python）就好。
詳細步驟、每個欄位的意思，看 [`mods/README.md`](mods/README.md)。

## 專案結構

```
engine/     遊戲引擎本體：畫面繪製、輸入處理、mod 載入與驗證、戰鬥流程。
            這裡的程式碼不需要修改。
mods/       遊戲實際的內容：卡牌、怪物、規則、關卡。要加東西都在這裡動手。
            見 mods/README.md。
tests/      自動化測試（pytest）。
tools/      開發用的小工具，跟遊戲本身無關。
assets/     字型等靜態資源。
main.py     啟動點。
```
